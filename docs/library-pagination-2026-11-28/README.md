# Browse the complete saved transcript library — 2026-11-28

Parent `b8f6af5eac61ed2e95134ad1f719c0c4b6c5bb84`; draft PR #2. Its exact PR-triggered [platform run](https://github.com/YellowBrokeIt/LinkScribe/actions/runs/46164830861) completed successfully. This does not establish new language-model or provider quality.

Before this change, the library endpoint returned at most 100 results (50 by default) and the browser never requested further pages. With more than 50 saved transcripts or matching search results, the remaining records were inaccessible through the listing. The new API preserves the items field and adds an optional next_cursor, seeking by descending (created_at,id). It fetches at most one extra preview row and does not load full transcript records. Equal timestamps have a deterministic tie-breaker. The cursor still works if its anchor was deleted, and newer inserts do not displace later pages. A refreshed search starts again from the newest matches. As with any live library, edits or restores can change matching membership between pages; this is not a frozen database snapshot. Existing list_items callers still receive a list. Existing Unicode/literal search semantics are preserved.

The browser adds Load more transcripts and an inline error/retry path. A request generation counter prevents a stale response replacing a newer search. The edit/open actions remain the same; saving/deleting/refreshing resets the listing to its first page.
