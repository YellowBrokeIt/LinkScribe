## Supported scope

The supported schema uses the pinned converter's older array-valued `items`
tuple branch and its verified anchored-pattern subset. It allows every ordering
of the exact markers within the correct original segment, with JSON-safe free
text gaps. This bounded corpus contains at most three markers per segment.
Every complete source message, source-derived spelling map, ordinary translation
instruction and semantic criterion remains unchanged.

Exact marker enforcement can still accompany wrong pronouns, changed roles,
missing facts or poor ordinary translation. The marker-only/empty-gap probes
intentionally demonstrate that structural constraints cannot establish meaning.
The source-derived name detector and article-boundary normalizer retain their
previously documented generalization limits. No heldout corpus, broader screen,
summary experiment, application integration or production-default switch was
performed or approved by this setup result.

The next model generation, if separately authorized after review, must bind the
actual grammar evidence and preserve full raw/restored output under the original
meaning rules. All earlier rejected translation profiles remain unchanged.
