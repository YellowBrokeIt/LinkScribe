# LinkScribe GitHub Pages preview

This branch hosts a static, interactive demonstration. It is not connected to the Python transcription backend. Clicking the demo button creates only example text locally in the browser. Real video URLs and uploaded files are never processed or sent anywhere by this site.

To activate publishing: Repository Settings → Pages → Deploy from a branch → gh-pages → /(root) → Save.

For the real app, use the main `master` branch.
